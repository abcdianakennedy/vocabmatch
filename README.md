# Vocabulary Match

A vocabulary card matching game for a classroom interactive whiteboard.
One HTML file. No account, no server.

Live: https://abcdianakennedy.github.io/vocabmatch/

- **Match** - all ten cards face up. Tap a word, then tap what it means.
- **Memory** - the same ten cards face down. Turn two and find a pair.
- **Word list** - the words and meanings, to read together before playing.
- **Words** - retype the list as `word = meaning` lines. It saves on the device,
  so the same page serves a new set of words every week.
